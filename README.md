# TP3 – Gestión de vehículos, conductores y viajes

Programación IV – Tecnicatura Universitaria en Programación – UTN FRLR.

Aplicación para registrar los vehículos de una empresa de transporte, sus conductores y los viajes realizados.

- `backend/`: API REST JSON con Express, MySQL (mysql2), express-validator, Passport + JWT y bcrypt.
- `frontend/`: aplicación Vite + React (JavaScript) con CSS puro.
